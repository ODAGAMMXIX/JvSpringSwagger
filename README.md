
# JvSpringSwagger
SpringBoot w/ Swagger

# ##Arquitetura de Desenvolvimento da PDPJ-Br## 

* Linguagem de programação Java 

* API RESTful 

    * Criação (POST) 

    * Leitura (GET) 

    * Atualização (PUT) 

    * Exclusão (DELETE) 

    * Códigos de status HTTP (200, 201, 400, 404, 204, 500) 

* JSON 

* Framework Spring 

    * Anotações (`@RestController`, `@RequestMapping`, `@GetMapping`, `@PostMapping`, `@PutMapping`, `@DeleteMapping`, `@PathVariable`, `@RequestBody`, `@Valid`, `@Autowired`) 

    * Injeção de Dependência (DI) 

* Spring Boot 

    * Starters (web, validation) 

* Swagger 

    * Documentação da API (OpenAPI) 

    * Anotações (`@Operation`, `@ApiResponses`, `@ApiResponse`) 

* Persistência 

    * JPA 2.0 
    * Hibernate 4.3+ 

    * `JpaRepository` 

* Ferramenta de versionamento Git
